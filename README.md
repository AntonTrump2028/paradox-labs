# Paradox Labs

Live Monte Carlo labs for probability paradoxes that break intuition.

| Lab | Gut | Math |
|---|---|---|
| [Monty Hall](src/lib/monty.ts) | remaining doors are equal | P(stay)=1/n, P(switch)=(1−1/n)/(n−1−k) |
| [Birthday](src/lib/birthday.ts) | 23 people ≈ 6% | ≈ 50.7% share a day |
| [False positive](src/lib/bayes.ts) | 99% test ⇒ 99% sick | PPV = se·π / (se·π + (1−sp)·(1−π)) |

RU / EN. Pause, reset, speed, parameter steppers. Frequencies converge to the formulas.
